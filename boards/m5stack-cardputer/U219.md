# Cardputer ADV + M5Stack Cap CC1101/NFC (U219)

This target adds a dedicated Bruce build for the official M5Stack U219 cap without changing the default Cardputer ADV pinout used by legacy PINGEQUA/Hydra-style caps.

## Hardware mapping

Shared SPI:

- SCK: GPIO40
- MOSI: GPIO14
- MISO: GPIO39

CC1101:

- CS: GPIO5
- GDO0: GPIO15
- RF_SW0: GPIO13
- RF_SW1: CC1101 GDO2, driven through IOCFG2
- Cap power enable: GPIO3

ST25R3916 NFC:

- CS: GPIO6
- IRQ: GPIO4
- Interface: SPI

The U219 RF front-end has three matched paths. The build switches them automatically:

- 315 MHz path: RF_SW0=0, GDO2/RF_SW1=1
- 433 MHz path: RF_SW0=1, GDO2/RF_SW1=0
- 868/915 MHz path: RF_SW0=1, GDO2/RF_SW1=1

## Build

From the repository root:

```bash
pio run -e m5stack-cardputer-u219
```

The firmware image is generated under:

```text
.pio/build/m5stack-cardputer-u219/
```

To upload directly over USB with PlatformIO:

```bash
pio run -e m5stack-cardputer-u219 -t upload
```

## Bruce configuration

The U219 target preselects:

- RF module: CC1101 SPI
- RFID/NFC module: ST25R3916 SPI
- U219 pinout above

No manual CC1101/ST25R3916 pin remapping should be necessary with this target.

## Notes

- Use the antenna matching the active band (315, 433, or 868/915 MHz).
- The default `m5stack-cardputer` target remains unchanged for the older cap.
- GPIO13 and GPIO15 are consumed by the U219, so the ADV GPS mapping on those pins is disabled in this target.
